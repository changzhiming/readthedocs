使用指南¶

本地构建¶

mkdocs serve

MkDocs 会在本地启动一个开发服务器。你可以实时预览文档。

部署到 Read the Docs¶

  1. 推送代码到 GitHub
  2. 登录 https://readthedocs.org/
  3. 点击 “Import a Project”
  4. 选择仓库，点击 “Next”
  5. 构建完成后访问：
    https://yourproject.readthedocs.io/
