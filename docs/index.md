# 欢迎来到 MkDocs RTD 模板

这是一个可以直接在 [Read the Docs](https://readthedocs.org/) 上构建的 MkDocs 示例。

---

## 🚀 快速开始

1. 克隆项目并安装依赖：

   ```bash
   pip install -r requirements.txt
   mkdocs serve
   ```

2. 本地打开浏览器访问：  
   [http://127.0.0.1:8000](http://127.0.0.1:8000)

3. 推送到 GitHub，然后在 Read the Docs 导入你的仓库。
